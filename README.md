# 📚 IP 학습 Wiki

IP·특허 출원 업무와 진단 관점을 틈틈이 학습하기 위한 개인 Wiki입니다.

> **큰 그림:** IP 기초 개념을 이해하고 → 출원 프로세스의 각 Gate를 이해하고 → 이를 받치는 업무체계를 연결해서 → 실제 진단 인터뷰와 데이터 분석에 활용한다.

---

## 01. IP 기초

### [명세서 기초](docs/glossary/specification-basics.md)
명세서의 역할, 발명의 설명과 청구범위의 관계, 최초 명세서가 중요한 이유를 정리.

앞으로 추가할 내용: 특허/실용신안, 독립항·종속항, 출원일·공개일·등록일, 파리조약·PCT, 인용·피인용 등.

---

## 02. 출원 프로세스

### [특허 출원 프로세스 큰 그림](docs/prosecution/application-process.md)
**발명 발굴·신고 → 출원평가/등급 → 명세서·청구항 → 국내·해외출원 → OA/심사 → 등록/종료 → Feedback** 흐름과 단계별 핵심 Gate를 정리.

핵심 관점은 단순 절차 준수가 아니라 각 단계에서 **무엇을 판단하고, 누가 승인하며, 잘못되면 어떤 권리 리스크가 생기는지**를 이해하는 것.

---

## 03. 업무체계

### [출원 업무체계](docs/operation/operating-framework.md)
출원 프로세스를 받치는 **조직·R&R / 인력·전문성 / 대리인 / 시스템·데이터 / KPI·성과 / 비용·통제**를 정리.

핵심 관점은 **제도가 존재하는가가 아니라 실제로 목적에 맞게 작동하는가**를 확인하는 것.

---

## 04. IP 진단 / 감사

### ⭐ [출원 프로세스·업무체계 진단 인터뷰 가이드](docs/audit/interview-guide.md)
실제 인터뷰 직전에 다시 볼 핵심 학습 페이지.

오늘 문답에서 정리한 내용을 기반으로 다음 구조로 정리:

> **현업 설명 → 잠재 Risk → 확인 질문 → 필요 데이터 → 판단**

주요 주제:
- 출원등급 평가의 일관성과 Calibration
- 명세서·청구항의 발명자/IP담당자 Interface Risk
- OA 보정과 권리범위 변화
- 등록률 KPI의 함정
- IP담당자의 기술 전문성
- 외부 대리인 평가와 Selection Bias
- 시스템 자동기한 Logic/Input 통제
- Excel 이중관리와 System of Record
- KPI가 구성원 행동에 미치는 영향

## 🧭 진단할 때 기억할 한 문장

> **“기준이 있다”는 설명에서 끝내지 말고, 그 기준이 실제로 일관되게 작동했는지를 사례와 데이터로 검증한다.**

### 인터뷰 5단계

**① 현업 설명 → ② 무엇이 잘못될 수 있는가 → ③ 통제는 어떻게 설계됐는가 → ④ 실제 사례/데이터 확인 → ⑤ 예외의 원인 추적**
