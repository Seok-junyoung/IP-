# 출원 프로세스·업무체계 진단 인터뷰 가이드

> 목적: 피진단부서의 설명을 단순히 듣는 데 그치지 않고, **통제의 존재 → 설계 → 실제 운영 → 데이터 검증 → 원인**까지 연결해 확인한다.

## 1. 인터뷰의 기본 사고방식

현업이 “기준이 있다”, “시스템으로 관리한다”, “등록률이 높다”고 설명하더라도 그것만으로 프로세스가 적정하다고 판단하지 않는다.

**현업 설명 → 잠재 Risk → 확인 질문 → 필요 데이터 → 판단** 순으로 접근한다.

| 현업 설명 | 잠재 Risk | 확인 질문 | 데이터 검증 예시 |
|---|---|---|---|
| 평가기준이 시스템에 등록되어 있음 | 평가자·조직별 적용 편차 | 평가 결과를 Calibration하는 절차가 있는가? | 기술분야×평가자×등급 분포 |
| 등록률이 90% 이상 | 등록을 위해 권리범위를 과도하게 축소할 가능성 | 최초 의도한 권리범위 유지 여부도 관리하는가? | 최초/현재 청구항, OA·보정 이력 |
| 우수 대리인에게 물량을 집중 | 등록률·속도 중심 평가로 실질 품질 미반영 | 권리화 품질을 직접 평가하는 항목이 있는가? | 동일 등급·기술군별 대리인 성과 비교 |
| 해외출원 기한을 시스템 자동관리 | Logic/Input 오류 | 기한 산출 로직과 입력값 정확성을 어떻게 검증하는가? | 실제 우선일 기준 재계산 후 시스템과 대조 |
| 담당자가 별도 Excel도 관리 | System of Record 불명확, 인수인계 위험 | 시스템과 Excel 불일치 시 무엇이 공식정보인가? | 시스템↔Excel 샘플 대사 |

## 2. 출원 프로세스를 Gate로 이해하기

출원 프로세스는 단순 업무 순서가 아니라 각 단계에서 **판단과 통제가 이루어지는 Gate의 연속**으로 본다.

1. **발명 발굴·신고** — 좋은 발명이 누락 없이 들어오는가?
2. **출원평가·등급** — 중요도와 권리화 방향을 일관된 기준으로 판단하는가?
3. **명세서·청구항 작성** — 발명의 핵심이 실제 권리범위에 적절히 담기는가?
4. **국내·해외출원** — 결정된 국가와 법정기한에 맞게 실행되는가?
5. **OA/심사 대응** — 등록을 위해 최초 권리범위를 과도하게 훼손하지 않는가?
6. **등록/종료** — 최초 확보하려던 권리를 실제로 어느 정도 확보했는가?
7. **Feedback** — 거절·포기·기술환경 변화 등의 결과가 다음 평가와 출원에 반영되는가?

## 3. 출원평가·등급

### 주요 Risk
- 기술성·사업성·권리성 등 정성평가 기준의 모호성
- 평가자/조직별 등급 부여 편차
- 평가기준은 있으나 실제 적용에 대한 Calibration 부재
- 최초 등급 이후 환경 변화에 대한 재평가 미흡

### 인터뷰 질문
- 기술성·사업성·권리성 아래 세부 평가항목과 배점은 어떻게 구성되어 있는가?
- 연구조직과 IP조직의 평가점수 및 가중치는 어떻게 반영되는가?
- 평가자별·조직별 등급 분포 편차를 정기적으로 확인하는가?
- 평가자 간 의견이 다른 경우 최종 등급은 누가 어떤 근거로 결정하는가?
- 최초 등급이 변경된 사례와 변경 사유·승인 절차는 무엇인가?
- 기술·사업환경이 달라졌을 때 등급 또는 해외출원 필요성을 재검토하는가?

### 데이터 검증
`기술분야 × 평가자 × 평가점수 × 최종등급`을 분석해 구조적 편향 여부를 확인한다. 단, 동일 기술분야라도 개별 발명은 다르므로 **등급 차이 자체를 결함으로 단정하지 않는다.**

## 4. 명세서·청구항 및 R&R

### 주요 Risk
발명자는 기술내용, IP담당자는 권리범위를 각각 검토하는 식으로 역할이 분리될 경우 **발명의 핵심 기술과 청구항 사이의 Interface Risk**가 발생할 수 있다.

### 인터뷰 질문
- 대리인 초안에서 발명자·IP담당자는 각각 무엇을 검토하는가?
- 발명의 핵심 기술이 독립청구항에 적절히 반영됐는지는 누가 최종 검증하는가?
- A1/A2 등 중요특허와 일반특허의 검토 수준에 차이가 있는가?
- OA 과정에서 청구항을 보정할 때 발명자 재검토가 필수인가?
- 권리범위를 축소하는 보정에 별도 승인 기준이 있는가?

### 핵심 관점
**청구항 개수 감소 = 권리범위 축소**로 단정할 수 없다. 최초 독립항과 현재/등록 독립항의 실제 문구를 비교해 판단해야 한다.

## 5. OA·심사와 등록률

높은 등록률은 좋은 성과일 수 있지만 **좋은 특허를 확보했다는 의미와 동일하지 않다.**

예를 들어 최초 `A+B`로 청구했던 권리가 심사 대응 과정에서 `A+B+C+D+E`로 좁아져 등록됐다면 등록 KPI는 성공이지만 실질 권리범위는 약해졌을 수 있다.

### 인터뷰 질문
- 전체 등록률뿐 아니라 A1/A2/B 등급별 등록률은 어떻게 되는가?
- 최초 출원 시 의도한 권리범위가 등록 시점까지 얼마나 유지됐는지 관리하는가?
- OA 대응안을 누가 작성·검토·승인하는가?
- 발명자 의견 없이 IP담당자와 대리인만으로 보정 가능한 경우는 무엇인가?

## 6. IP담당자 전문성

변리사 자격이나 장기간 IP경력은 법률·IP 전문성의 근거가 될 수 있지만 **해당 반도체 기술분야의 전문성을 자동으로 보장하지 않는다.**

### 확인 포인트
- IP담당자의 전공·기술경력과 담당 연구영역의 매칭
- 신규 기술 담당 시 교육/학습 체계
- 연구조직과의 기술 협업 방식
- 특정 기술이 한 명에게 집중되는 Key-person risk
- 담당자별 업무량과 중요특허 집중도

## 7. 외부 대리인 관리

### 평가제도에서 의심할 점
등록률, 처리기한 준수율, 연구원 만족도는 유용한 운영지표지만 **권리화 품질을 직접 보여주는 지표는 아닐 수 있다.**

### 인터뷰 질문
- 대리인 평가항목별 배점과 정성/정량평가 비중은?
- 기술분야별 전문성을 어떤 기준으로 판단해 사건을 배정하는가?
- 평가 결과가 실제 다음 연도 물량 배정에 어느 정도 반영되는가?
- 하위평가 대리인에게 계속 물량이 배정되는 예외가 있는가?
- 최초 의도한 권리범위 확보 수준을 평가하는 품질지표가 있는가?

### 데이터 비교 시 주의
A법인에 A1/A2 등 좋은 사건이 집중돼 있다면 높은 등록률이 대리인 역량 때문인지 사건 특성 때문인지 구분하기 어렵다. 따라서 가능하면 **동일 기술분야 + 동일 등급 + 유사 출원연도** 조건으로 대리인을 비교한다.

## 8. 시스템·데이터·기한 통제

### 주요 Risk
- 자동 산출 Logic 오류
- 출원일/우선일 등 Input 오류
- 시스템과 Excel의 이중관리
- 담당자 개인파일 의존
- 인수인계 및 Key-person risk

### 인터뷰 질문
- 해외출원/PCT 기한 산출 로직은 어떻게 검증하는가?
- 기한 계산의 기준값은 누가 입력하고 누가 검증하는가?
- 시스템 변경 시 테스트 절차가 있는가?
- 시스템 밖에서 이메일·Excel·개인파일로 관리하는 업무는 무엇인가?
- 시스템과 Excel 정보가 다를 경우 공식정보는 무엇인가?
- 최근 기한 초과/임박 건을 별도 집계하고 있는가?

## 9. KPI와 행동유인

KPI는 단순 측정지표가 아니라 **구성원의 행동을 유도하는 장치**로 본다.

`출원 처리건수 ↑ + 기한준수율 ↑ + 등록률 ↑` 중심 KPI는 상황에 따라 **많이 출원하고, 빨리 처리하고, 권리범위를 좁혀서라도 등록시키는 행동**을 유도할 수 있다.

### 인터뷰 질문
- 회사가 양보다 질 중심으로 전환했다면 담당자 KPI도 변경됐는가?
- 출원건수·등록률 외에 고등급 특허, 권리화 품질 등을 반영하는가?
- KPI 달성을 위해 저가치 출원이나 과도한 보정이 발생하지 않는지 어떻게 확인하는가?

피인용과 같은 장기성과는 특허 가치 판단에 참고할 수 있지만, 가치가 드러나기까지 시간이 걸리므로 당해년도 개인 KPI에 단순 적용하는 것은 별도로 검토해야 한다.

## 10. 인터뷰에서 기억할 5단계

> **① 현업 설명을 듣는다 → ② 무엇이 잘못될 수 있는지 생각한다 → ③ 통제가 어떻게 설계됐는지 묻는다 → ④ 실제 사례/데이터를 요구한다 → ⑤ 예외의 원인을 파고든다.**

특히 “문제가 없습니다”, “시스템으로 관리합니다”, “기준이 있습니다”, “등록률이 높습니다”, “지금까지 사고가 없었습니다”라는 설명은 **결론이 아니라 검증의 시작점**으로 본다.
